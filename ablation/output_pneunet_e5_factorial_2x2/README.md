# Faktorial CLAHE × augmentasi

Empat kondisi E5: baseline, CLAHE saja, augmentasi saja, serta CLAHE + augmentasi. Seluruh kondisi memakai normalisasi /255 agar skala intensitas sama.

[Notebook sumber](../PneuNet_E5_Factorial_2x2_CLAHE_Augmentation.ipynb) · [Peta seluruh studi](../README.md)

Folder ini memuat artefak dari output_pneunet_e5_factorial_2x2/output_pneunet_e5_factorial_2x2. Susunan internal hasil dipertahankan, sementara pembungkus folder unduhan yang berulang sudah dirapikan. Semua CSV, JSON, PNG dan NPZ heatmap yang tersedia disertakan. Bobot checkpoint dan duplikat otomatis notebook dikecualikan. Rujukan best.pt pada metadata merupakan lokasi eksperimen asli dan tidak menyatakan bahwa bobot ikut disertakan.

README pada setiap subfolder menjelaskan tipe hasilnya. File konfigurasi dan result/summary menjadi sumber angka penelitian. Gambar Grad-CAM merupakan analisis kontribusi fitur, bukan mask anotasi ahli atau pengukuran akurasi segmentasi.
